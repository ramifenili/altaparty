# Imágenes de "Fiesta de Campeones"

Para cambiar una imagen, **reemplazá el archivo de esta carpeta con el mismo nombre** y recargá la página
(no hace falta tocar código ni el panel). Se acepta PNG, WebP o JPG (se prueba en ese orden).
Si un archivo falta, la plantilla se ve igual con una alternativa dibujada.

| Archivo | Dónde se usa | Recomendado |
| --- | --- | --- |
| `escudo.png` | Escudo tenue de fondo en la presentación y escudo de la pantalla de la hora | PNG transparente, vertical (≈ 260×380) |
| `equipo.png` | Presentación: grupo de jugadores detrás de la cinta con el nombre | PNG con bordes difuminados o transparentes, ≈ 1080×1340 |
| `dt.png` | "Estás convocado": figura abajo a la derecha | PNG transparente, ≈ 700×940 |
| `accion.png` | "A las…": jugador pateando, abajo | PNG transparente, apaisado (≈ 860×920) |
| `hinchas.png` | "Te espero en…": banda de hinchas abajo (el borde de arriba se desvanece) | ≈ 1080×960 |
| `noche.png` | Cierre en el estadio: grupo abajo (el borde de arriba se desvanece) | ≈ 1080×1150 |
| `pelota.png` | La pelota que rueda en "Estás convocado" y en el resumen final | PNG transparente, cuadrada (≈ 600×600), sin sombra (la sombra se dibuja sola) |
| `messi-copa.png` | Imagen para compartir, solo cuando se carga una foto: Messi besando la copa, a la izquierda del círculo de la foto | PNG transparente, apaisado (≈ 206×175 o mayor) |

La foto del cumpleañero no va acá: la sube cada cliente en el formulario.
Las imágenes originales se recortaron de un video de referencia; usalas solo si tenés licencia para ellas.

La tipografía es **Red Hat Display** (`public/fonts/RedHatDisplay.woff2`, variable 400–900, licencia OFL).
