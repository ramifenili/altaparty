# Imágenes de la plantilla "HUNTR/X: Cazadoras K-pop"

Poné acá los PNG de Rumi, Mira y Zoey (mejor con **fondo transparente**, cuerpo completo, proporción ~2:3) con **estos nombres** y recargá: no hace falta tocar código. También valen WebP, JPG, GIF animado o WebM/MP4.

Mientras falte una imagen se dibuja una silueta de neón con el nombre del archivo que corresponde. Si hay algunas de una protagonista pero no todas (por ejemplo solo `rumi-1.png`), las demás poses usan esa. Mantené el diseño original de cada personaje.

| Archivo                         | Dónde se usa                                                                                  |
| ------------------------------- | --------------------------------------------------------------------------------------------- |
| `grupo-1.png`                   | Intro (0–4 s): las tres juntas, cuerpo completo, pose de equipo                               |
| `rumi-1.png`, `rumi-2.png`      | Presentación de Rumi (primer plano grande y otra pose)                                        |
| `mira-1.png`, `mira-2.png`      | Presentación de Mira                                                                          |
| `zoey-1.png`, `zoey-2.png`      | Presentación de Zoey                                                                          |
| `grupo-2.png`                   | Bloque del cumpleañero: grupal que baja y se achica para dejar lugar a la foto                |
| `rumi-3.png`, `mira-3.png`, `zoey-3.png` | Celebración (¡MÚSICA! ¡BAILE! ¡DIVERSIÓN!) y, recortadas por la mitad de arriba, tarjeta de datos |
| `grupo-3.png`                   | Final de la celebración (distinta de `grupo-1` y `grupo-2`)                                   |
| `rumi-4.png`, `zoey-4.png`, `mira-4.png` | Invitación: Rumi a la izquierda, Zoey a la derecha y Mira abajo al centro            |

Las imágenes individuales van **apoyadas abajo** (los pies en el borde inferior de la imagen) y las grupales, de ancho completo. En la tarjeta final se usa solo la mitad de arriba de `rumi-3`, `mira-2` y `zoey-3`.

Paleta: violeta `#8B35FF`, magenta `#F32BBD`, rosa `#FF5A91`, celeste `#32DFFF`, azul oscuro `#100C2C`.
Música: `public/audio/cazadoras.wav` (original, generada con `node scripts/generate-huntrx-audio.mjs`; cada corte de escena cae en un tiempo fuerte a 120 BPM).
