# Imágenes de "Juguetes en acción"

Para cambiar una imagen, **reemplazá el archivo de esta carpeta con el mismo nombre** y recargá la página
(no hace falta tocar código ni el panel). Se acepta PNG, WebP o JPG (se prueba en ese orden).
Si un archivo falta, esa parte simplemente no se dibuja y la plantilla sigue funcionando.

Cada juguete es una imagen **separada** y tiene su propio movimiento. Apoyalos por el borde de abajo (pies) y, de ser
posible, mirando hacia el centro. Si un personaje no tiene archivo, simplemente no aparece.

`grupo.png` (el grupo junto) ya no se usa; podés borrarlo.

La tipografía de los títulos es **Gill Sans Ultra Bold** (`public/fonts/GillSansUltraBold.ttf`). La foto del cumpleañero
no va acá: la sube cada cliente en el formulario. Las imágenes originales se recortaron de videos de referencia; usalas solo
si tenés licencia para ellas.
